# Imágenes clínicas y educativas

Sube aquí los bloques de imágenes pendientes de integrar en la aplicación.

## Reglas de nombres
- minúsculas
- sin espacios ni acentos
- usar guion bajo (`_`)
- conservar nombres acordados, por ejemplo `edu_atm_anatomia.webp`

> Carpeta de recepción. Las imágenes no se integrarán al código de la app hasta finalizar la carga y revisión.
