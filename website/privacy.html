Aviso y política de privacidad

Política de Privacidad

Última actualización: 14 de septiembre de 2026.

Resumen: la aplicación Android está diseñada para uso educativo offline. No solicita una cuenta, no declara permiso de Internet y no está diseñada para almacenar expedientes clínicos reales.

1. Alcance

Esta política describe el tratamiento de información en la aplicación Android y en el sitio web de El expediente del dentista, proyecto educativo independiente orientado al aprendizaje del llenado del expediente clínico odontológico.

2. Datos personales en la aplicación Android

La aplicación no requiere registro, inicio de sesión, correo electrónico, número telefónico ni creación de una cuenta. Su archivo de manifiesto no declara permiso de Internet. La experiencia está diseñada para trabajar sin conexión.

Las prácticas clínicas de la app deben realizarse con información ficticia o simulada. La app no está concebida como sistema de expediente clínico electrónico ni como repositorio de datos de pacientes.

3. Información almacenada localmente

La app guarda únicamente preferencias de uso en el dispositivo, como idioma, tratamiento de Doctor/Doctora, paleta visual, tipografía y estado del proceso inicial. Esas preferencias se guardan en almacenamiento privado de la aplicación. La sesión educativa de trabajo —incluido el registro rápido de signos y síntomas— se mantiene en memoria durante la ejecución.

El respaldo automático de la aplicación está deshabilitado en la configuración Android actual.

4. Internet, analítica, publicidad y rastreo

  • La aplicación Android no declara permiso de Internet.
  • No se integran redes publicitarias.
  • No se integran SDK de analítica o rastreo de terceros.
  • No se venden datos personales.
  • No se comparte información clínica con servidores del proyecto.

5. Uso de inteligencia artificial durante el desarrollo

Parte del contenido textual, visual, ilustraciones educativas, organización de información y apoyo de redacción de esta aplicación fue creado o refinado con asistencia de ChatGPT (OpenAI). El material fue posteriormente revisado, seleccionado y adaptado por el autor del proyecto.

ChatGPT/OpenAI se utilizó como herramienta de apoyo durante el desarrollo. La aplicación Android instalada no se conecta a ChatGPT/OpenAI y no comparte automáticamente datos personales, clínicos ni información sensible con ChatGPT/OpenAI. La mención de ChatGPT/OpenAI reconoce la herramienta utilizada y no implica patrocinio, certificación clínica ni respaldo de OpenAI al proyecto.

6. Sitio web y calculadoras

Este sitio es estático y no incorpora registro de cuentas, publicidad, píxeles de seguimiento ni herramientas propias de analítica. El alojamiento se realiza mediante GitHub Pages. Como proveedor de infraestructura, GitHub puede procesar datos técnicos necesarios para atender solicitudes web conforme a sus propias políticas.

Los campos del registro rápido de signos y síntomas y de las calculadoras clínicas se procesan mediante JavaScript en el navegador. El proyecto no incluye una función que envíe esos valores a un servidor ni los guarda en una base de datos. Al recargar o cerrar la página, esos valores no se conservan por el sitio.

Las calculadoras de dosis pediátrica y anestésicos locales son herramientas matemáticas educativas. No seleccionan medicamentos, no emiten prescripciones y no sustituyen la ficha técnica, protocolos institucionales, valoración clínica ni juicio profesional.

7. Descarga de la APK

El botón de descarga apunta a la APK generada automáticamente desde el repositorio de GitHub. Cada actualización publicada en la rama principal puede reemplazar la APK disponible en esta página. La versión de prueba puede identificarse como compilación Preview mientras el proyecto permanezca en fase de evaluación.

8. Uso educativo y datos sensibles

No introduzcas nombres, domicilios, teléfonos, números de expediente, imágenes identificables, antecedentes médicos u otros datos reales de pacientes. Los módulos de razonamiento diagnóstico y cálculo son material de apoyo académico y no sustituyen la valoración clínica, las pruebas diagnósticas, la prescripción, el juicio profesional ni las normas aplicables.

9. Menores de edad

La app no solicita información personal de menores ni de adultos. Si se utiliza en actividades docentes, el responsable de la clase debe emplear casos ficticios y observar las reglas institucionales aplicables.

10. Seguridad

El diseño offline de Android reduce la exposición de datos al no enviar contenido clínico a un servidor del proyecto. En la web, los nuevos cálculos se realizan localmente en el navegador. Sin embargo, ningún software puede garantizar seguridad absoluta. Se recomienda mantener Android y el navegador actualizados y descargar la APK únicamente desde esta página o desde el repositorio oficial.

11. Cambios a esta política

Esta política podrá actualizarse cuando cambien las funciones de la aplicación, el sitio web o la forma de tratamiento de información. La versión vigente se publicará en esta misma dirección y quedará versionada en GitHub.

12. Contacto y código fuente

Para revisar el código, reportar un problema de privacidad o consultar cambios del proyecto, utiliza el repositorio oficial: github.com/yomismtz/El-expediente-del-dentista.

Esta política describe el comportamiento técnico actual del proyecto y no constituye asesoría jurídica.
